Plugin Roblox Studio

Installe tes scripts en un clic

Le plugin Bloxia récupère ton pack et pose tous les scripts au bon endroit dans ton jeu, directement dans Roblox Studio. Fini le copier-coller.

Télécharger le plugin (bloxia.lua)
  1. 1 Télécharge le pluginClique sur le bouton ci-dessus pour récupérer le fichier bloxia.lua.
  2. 2 Ajoute-le à StudioDans Roblox Studio : crée un Script (clic droit sur ServerScriptService → Insert Object → Script), ouvre bloxia.lua, copie tout le code et colle-le dans ce Script. Puis clic droit sur le Script → « Save as Local Plugin », nomme-le « Bloxia ». Supprime ensuite le Script, il est devenu un plugin.
  3. 3 Connecte ton compteVa dans ton espace Bloxia → Roblox Studio, copie ton code d'appairage. Dans Studio, ouvre Bloxia depuis la barre d'outils (onglet Plugins), colle le code et clique « Installer ».
Autorise les requêtes HTTP : la première fois, Studio te demande d'autoriser le plugin à accéder à Internet (pour récupérer ton pack). Clique « Allow ».
